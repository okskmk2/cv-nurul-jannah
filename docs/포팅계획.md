# Next.js → Astro 포팅 계획

대상: `cv-nurul-jannah` (CV. Nurul Jannah / Moringga B2B 사이트)  
작성일: 2026-09-12  
전제: 공개 URL, 메타, JSON-LD, Cloudflare Email Sending은 동등하게 유지한다. UI를 다시 디자인하지 않는다.

---

## 1. 왜 옮기는가

이 사이트는 앱이 아니라 **다국어 마케팅·카탈로그 사이트**다. 페이지 거의 전부가 정적 HTML로  sufficed하고, 서버가 필요한 곳은 문의 메일 API 하나다.

지금은 Next.js App Router + OpenNext로 Cloudflare Workers에 올린다. 페이지 컴포넌트 15개가 `"use client"`라 본문 HTML은 나와도 hydration JS가 필요 이상으로 실린다. Astro로 바꾸면:

- 페이지는 빌드 타임 HTML
- JS는 문의 폼·헤더 메뉴·언어 전환만 island로 로드
- OpenNext 변환층이 사라져 Worker가 얇아진다

SEO의 핵심(완성된 HTML, canonical, hreflang, sitemap, JSON-LD)은 프레임워크가 아니라 **URL과 마크업 동등성**이다. 포팅 성공 기준은 “구글이 보는 문서가 지금과 같거나 더 가볍다”이다.

## 2. 현재 상태 (옮기기 전에 고정할 사실)

### 2.1 스택

| 항목 | 현재 |
| --- | --- |
| 프레임워크 | Next.js 16 App Router, React 19 |
| 스타일 | Tailwind CSS v4 (`@import "tailwindcss"`) |

### 2.2 URL (깨지면 안 됨)

영어는 prefix 없음. 나머지 로케일은 prefix.

| 경로 | 설명 |
| --- | --- |
| `/` `/products` `/trust` `/contact` | 영어 (default) |
| `/products/{slug}` | 제품 6개 |
| `/id/*` `/ko/*` `/ar/*` | 동일 구조 |
| `/api/contact` | POST only |
| `/sitemap.xml` `/robots.txt` | SEO |
| `/opengraph-image` | OG 1200×630 (런타임 ImageResponse) |
| `/en`, `/en/:path*` | `/`, `/:path*` 로 리다이렉트 (middleware + next.config) |

슬러그: `moringa-coffee`, `moringa-tea`, `moringa-crackers`, `moringa-powder`, `moringa-noodle`, `moringa-stick`.

로케일: `en` (default), `id`, `ar`, `ko`. `ar`는 `dir="rtl"`.

### 2.3 SEO 산출물

- `metadataBase` = `https://cvnuruljannah.com`
- 페이지별 title / description / canonical
- `alternates.languages` (en, id, ar, ko, x-default)
- Open Graph + Twitter `summary_large_image`
- Organization JSON-LD (모든 페이지), Product JSON-LD (제품 상세)
- sitemap: 정적 4경로 × 4로케일 + 제품 6 × 4로케일, hreflang 포함
- robots: `/` allow, `/api/` disallow, sitemap·host
- Google Search Console 토큰: `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION`
- 파비콘/애플 아이콘: `/logo.png` (app `icon.png` / `apple-icon.png`도 존재)

### 2.4 서버 동작

`POST /api/contact`

1. IP당 60초 5회 제한
2. `parseInquiry` 검증 (`src/lib/contact.ts`)
3. honeypot `website` 가 있으면 200만 반환 (메일 안 보냄)
4. `env.EMAIL.send` — from `noreply@cvnuruljannah.com`, to `export@cvnuruljannah.com`, replyTo = 방문자

페이지는 전부 정적이다. ISR/SSR 페이지는 없다.

### 2.5 클라이언트 JS가 실제 필요한 곳

| 컴포넌트 | 진짜 필요한 이유 |
| --- | --- |
| `ContactForm` | 폼 상태, fetch, honeypot |
| `Header` | 모바일 메뉴 `open` |
| `LanguageSwitcher` | `<select>` onChange로 로케일 경로 이동 |
| `ProductFilters` | 카테고리 필터 — **지금은 `all` 하나뿐**이라 JS 불필요 |

나머지 (`HomePage`, `ProductsPage`, `TrustPage`, `ProductDetail`, `ProductCard`, `Footer`, `ContactPage`, `MobileStickyCta`, `LocaleLink`)는 `useLanguage()` 때문에 클라이언트일 뿐이다. 로케일을 페이지에서 prop으로 주면 **Astro 정적 컴포넌트로 충분**하다.

## 3. 목표 아키텍처

```
요청
 ├─ 정적 HTML (페이지 전부)     ← Cloudflare Assets
 ├─ /sitemap.xml /robots.txt    ← 빌드 산출물
 ├─ /opengraph-image.png        ← 빌드 산출 정적 PNG
 └─ POST /api/contact           ← Worker only (prerender=false)
```

- **Astro** 페이지 + 레이아웃 (기본 0 JS)
- **React island** 3개: `ContactForm`, `Header` (모바일 메뉴), `LanguageSwitcher`
- **Cloudflare adapter** (`@astrojs/cloudflare`) — OpenNext 제거
- Tailwind v4는 Vite 플러그인으로 유지
- `site: "https://cvnuruljannah.com"`, `trailingSlash: "never"` (현재 Next 기본과 동일)

렌더 모드: 기본 **정적 prerender**. 문의 API만 `export const prerender = false`.

영어 페이지와 `[locale]` 페이지는 **같은 콘텐츠 컴포넌트**를 호출하는 얇은 래퍼다. 페이지 본문을 4벌 복사하지 않는다.

### 5.5 Open Graph 이미지

현재: 요청 시 `next/og` ImageResponse (Satori). Cloudflare Workers에서 동일 런타임을 재현하지 않는다.

계획:

1. 기존 레이아웃(크림 배경, 로고, 카피)을 빌드 스크립트 또는 커밋된 PNG로 `public/opengraph-image.png`에 둔다.

## 6. i18n 설정

`astro.config.mjs`:

```js
i18n: {
  defaultLocale: "en",
  locales: ["en", "id", "ar", "ko"],
  routing: {
    prefixDefaultLocale: false,
    redirectToDefaultLocale: true, // /en → /
  },
}
```

파일 구조가 URL과 일치해야 한다. 그래서 영어는 `src/pages/*.astro`, 나머지는 `src/pages/[locale]/*.astro`다.

`Astro.currentLocale`과 기존 `routing.ts`의 `localizedPath` / `absoluteUrl`을 같이 쓴다. hreflang 링크는 레이아웃에서 `languageAlternates(path)`로 찍는다. 이 헬퍼는 `lib/seo.ts`에 남긴다 (Next `Metadata`만 제거).

아랍어 페이지: `<html lang="ar" dir="rtl">`.

## 7. 문의 API (Cloudflare Email)

`src/pages/api/contact.ts`:

```ts
export const prerender = false;

export async function POST({ request, locals, clientAddress }: APIContext) {
  // rate limit, parseInquiry, honeypot, EMAIL.send — 현재 route.ts와 동일
}
```

바인딩 접근: Cloudflare adapter의 `locals.runtime.env.EMAIL` (어댑터 버전에 맞춰 `env.EMAIL` 확인). `cloudflare-env.d.ts`의 `SendEmail` 타입은 재사용.

레이트리밋은 현재처럼 프로세스 메모리 `Map`. Workers는 인스턴스가 갈라질 수 있어 **지금과 같은 수준**(완화된 남용 방지)만 유지한다. Durable Object/KV는 이번 범위 밖.

폼 fetch URL은 계속 `POST /api/contact`. CORS 불필요 (동일 오리진).

## 9. wrangler / 배포

목표 `wrangler.jsonc` 골격:

- `name`: `cv-nurul-jannah` (Worker 이름 유지 → 커스텀 도메인 그대로)
- `compatibility_date` / `nodejs_compat` 유지
- `send_email: [{ "name": "EMAIL" }]` 유지
- `main` / `assets`는 `@astrojs/cloudflare` 산출에 맞춤 (구현 시 어댑터 문서 값으로 확정)
- OpenNext `WORKER_SELF_REFERENCE` 삭제
- `keep_vars: true` 유지

스크립트:

```json
{
  "dev": "astro dev",
  "build": "astro build",
  "preview": "astro build && wrangler dev",
  "deploy": "astro build && wrangler deploy",
  "lint": "eslint ."
}
```

Workers Builds:

| 설정 | 값 |
| --- | --- |
| Build command | `npm run build` (`astro build`) |
| Deploy command | `npx wrangler deploy` |

README의 “`next build`를 CI 빌드 커맨드로 쓰지 마라” 문구는 Astro 기준으로 교체.

`public/_headers`의 `/_next/static/*` 캐시 규칙은 삭제. Astro hashed assets(`/_astro/*`)에 immutable 캐시를 건다. `catalog.pdf` Content-Disposition는 유지.

리다이렉트:

- `/en` → `/`
- `/en/:path*` → `/:path*`
- `/opengraph-image` → `/opengraph-image.png`

Astro `redirects` 또는 middleware. 영구(308)로 두되, 현재 next.config가 `/en`을 `permanent: false`로 둔 것은 구현 시 **308로 올려도 된다** (영어 prefix는 콘텐츠가 아니라 정규화).

## 10. 구현 순서

한 브랜치에서 진행한다. Next와 Astro를 오래 공존시키지 않는다. 중간 커밋은 “빌드가 되는 단위”로 나눈다.

이 단계 끝: `astro dev`로 빈 레이아웃이 뜬다.

### 2단계 — 데이터·SEO 헬퍼

### 4단계 — SEO 엔드포인트

## 12. 리스크와 결정

| 리스크 | 대응 |
| --- | --- |
| OpenNext → Astro adapter의 wrangler `main`/`assets` 경로 불일치 | 1단계에서 `astro build` 산출물을 보고 wrangler를 맞춘다. 추측으로 배포하지 않는다. |
| `EMAIL` 타입이 adapter locals 경로와 다름 | 구현 시 `@astrojs/cloudflare` 타입 (`env` vs `runtime.env`)을 코드로 확인. |
| OG URL 변경 | 301 유지. 메타는 `.png`로 통일. |
| 환경변수 이름 변경을 대시보드에서 안 함 | 배포 전 필수. 빼먹으면 Search Console 재검증만 깨지고 인덱스는 유지. |
| `ProductFilters`를 나중에 카테고리 추가 | 지금은 정적. 카테고리가 늘면 그때 island. |
| React Context 제거로 번역 누락 | `t(locale, key)`를 Astro frontmatter에서만 호출. 키는 dictionaries 그대로. |
| Workers 메모리 rate limit | 현재와 동일한 한계를 수용. |
